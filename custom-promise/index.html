Custom Promise Class Implementation

Implement a simplified Promise class that mimics native Promise behavior.

Class:

class MyPromise

Requirements:
  1. Internal States
    • pending
    • fulfilled
    • rejected
  2. Constructor
    • Accept executor function with resolve and reject.
    • Executor runs immediately.
  3. then Method
    • Supports chaining.
    • Returns a new MyPromise.
    • Must handle synchronous and asynchronous resolution.
  4. catch Method
    • Handles rejection.
    • Equivalent to then(null, onReject).
  5. finally Method
    • Executes regardless of resolve or reject.
    • Passes through original value.
  6. Error Propagation
    • Errors thrown in executor or handlers must propagate correctly.
  7. Async Behavior
    • Resolution callbacks must execute asynchronously.
    • Use microtask strategy.
Constraints:
  • No use of native Promise internally.
  • Must follow basic Promises/A+ behavior.
  • Handle multiple then calls before resolution.
Evaluation Criteria:
  • Correct chaining behavior
  • Proper state transitions
  • Async queue handling
  • Error bubbling
  • Clean internal structure
					
	class MyPromise {
	  constructor(executor) {
		this.state = "pending";
		this.value = undefined;
		this.reason = undefined;
		this.onResolve = [];
		this.onReject = [];
		this.onFinally = [];
		try {
		  executor(this.resolve.bind(this), this.reject.bind(this));
		} catch (error) {
		  this.reject(error);
		}
	  }
	  resolve(value) {
		if (this.state === "pending") {
		  this.state = "fulfilled";
		  this.value = value;
		  this.onResolve.forEach((fn) => fn(value));
		}
	  }
	  reject(reason) {
		if (this.state === "pending") {
		  this.state = "rejected";
		  this.reason = reason;
		  this.onReject.forEach((fn) => fn(reason));
		}
	  }
	  then(onResolve, onReject) {
		return new MyPromise((resolve, reject) => {
		  this.onResolve.push(() => {
			try {
			  const result = onResolve(this.value);
			  resolve(result);
			} catch (error) {
			  reject(error);
			}
		  });
		  this.onReject.push(() => {
			try {
			  const result = onReject(this.reason);
			  resolve(result);
			} catch (error) {
			  reject(error);
			}
		  });
		});
	  }
	  catch(onReject) {
		return this.then(null, onReject);
	  }
	  finally(onFinally) {
		this.onFinally.push(onFinally);
	  }
	}
